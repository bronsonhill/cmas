# Mesa

Mesa is a Python framework for building [[agent-based-model|agent-based models]], offered
in COMP90083 as an optional alternative to [[netlogo]].

## Key facts

- Python-based; assumes a solid understanding of object-oriented programming.
- Scales far beyond typical NetLogo use — models with millions of simultaneous agents are
  feasible, enabling city- and country-scale simulation.
- Optional in this subject: permitted for Project 2, but only touched on in tutorials.
  Using it is largely independent, self-directed work.
- Part of the broader 2000s–2010s wave of modelling-specific languages and libraries that
  made large-scale ABM practical.

## Relevance to CMAS

Mesa is the escape hatch for students who prefer Python or whose Project 2 model needs
more agents than NetLogo comfortably handles. The trade-off is that support in tutorials
is limited.
