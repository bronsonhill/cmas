# NetLogo

NetLogo is a high-level, widely used programming environment and language for building
[[agent-based-model|agent-based models]]. It is the primary modelling tool for COMP90083.

## Key facts

- Runs on Windows, macOS and Linux; free to install.
- Designed for scientists rather than professional software engineers, including
  researchers in the social sciences — deliberately easy to pick up.
- No prior knowledge is assumed in this subject; NetLogo is taught from the first
  tutorial. Coding demands overall are lower than in comparable subjects, though its
  unfamiliar syntax creates some initial friction.
- Ships with a model library, including the Flocking model used in the Week 1 lecture
  (see [[flocking]], [[boids]]) — `https://ccl.northwestern.edu/netlogo/models/Flocking`.
- Core modelling constructs covered in tutorials: defining agents, defining the
  environment, and specifying agent behaviours.
- Can be driven from Python; [[mesa]] is the optional alternative for very large models.
- The model library also supplies the [[schelling-segregation-model]], demonstrated live in
  Week 3a, and the [[netlogo-hiv-model]] under Biology, recommended for assignment extension
  ideas. Library models carry an Info tab describing the model in plain language alongside
  the code.

## Relevance to CMAS

NetLogo is the implementation vehicle for essentially all coursework: Project 1 extends a
supplied NetLogo model, and Project 2 may be built in NetLogo (or optionally Python/Mesa).
Installing it before the first tutorial is a stated prerequisite.
