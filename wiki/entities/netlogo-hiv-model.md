# NetLogo HIV Model

A model of HIV transmission in the [[netlogo]] Models Library, under Biology. Recommended in
the Week 3b lecture as a source of ideas for extending the basic [[sir-model]] in
Assignment 1.

## Key facts

- Found through the Models Library search box; the Info tab carries a plain-language
  description of the model alongside the code.
- Represents a sexually transmitted disease, so transmission occurs through explicit
  partner pairings rather than through undifferentiated contact.
- Includes behavioural factors that interact with transmission — the model is about
  behaviour affecting disease dynamics, not only about the disease.
- The lecturer noted its Info tab is not written as an [[odd-protocol]] description, but is
  detailed enough to understand the model without reading the source.

## Relevance

The model is offered as a contrast case: a very different disease system from SIR, showing
how far transmission structure can depart from the well-mixed assumption
([[contact-rate]]). Pairing partners rather than assuming everybody meets everybody is
exactly the kind of structural change the subject's [[model-extension]] heuristic points
toward, and doing it for a disease with a long infectious period changes the dynamics
substantially.

For Assignment 1 it is a worked precedent for adding states and behaviours to a
compartmental disease model rather than only tuning parameters.
